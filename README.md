## 📖 Overview
**Restaurant App** is a **Progressive Web App (PWA)** that allows users to **search, save, and review restaurants**.  
The application is designed with a focus on **performance, accessibility, and user experience**, including **offline support** with Workbox and persistent data storage with IndexedDB.

---

## ✨ Features
- 🍽️ **Restaurant Search & Details** → Explore restaurant information with dynamic data.  
- ⭐ **Add Reviews** → Users can submit reviews for restaurants.  
- ❤️ **Favorites Management** → Save and manage favorite restaurants using IndexedDB.  
- 📱 **Responsive Design** → Optimized for mobile and desktop devices.  
- ⚡ **Offline Mode** → Access the app even without an internet connection via Workbox caching.  
- 🖼️ **Image Optimization** → WebP format for faster loading.  
- ✅ **Testing** → Unit tests with Jest and end-to-end tests with CodeceptJS.

---

## 🏗 Tech Stack

**Frontend**
- HTML, CSS, JavaScript (ES6+)
- Webpack (bundling & optimization)

**Database**
- IndexedDB (via idb library)

**Testing**
- Jest (unit testing)
- CodeceptJS (end-to-end testing)

**PWA**
- Workbox for caching & offline support
